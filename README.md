# AI Business Knowledge Agent

An AI-powered knowledge assistant that uses Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and AI Agents to answer questions based on business documents.

## Project Goals

- Upload and process business documents
- Extract and prepare document content
- Generate embeddings
- Store and search document vectors
- Build a RAG pipeline
- Integrate an LLM
- Build an AI Agent with tool calling
- Create a web interface
- Deploy the application to the cloud

## Planned Technologies

- Python
- FastAPI
- LLM
- RAG
- Vector Database
- AI Agents
- React
- Docker
- Cloud Deployment
